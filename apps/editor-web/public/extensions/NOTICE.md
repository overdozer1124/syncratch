# Bundled Stretch3 extensions

These `.mjs` modules are regenerated by:

```bash
node scripts/stretch3-extensions/bundle.mjs
```

They adapt Stretch3 / community Scratch extensions that were originally
installed into `scratch-vm` via each project's `install.sh` into Xcratch-style
ESM modules (`export { blockClass, entry }`) for Syncratch's gallery.
